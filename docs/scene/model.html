scene::Model

A flat collection of meshes, each with its own local transform and material, plus one world placement for the whole group. Geometry only — no lights, no Camera or Renderer knowledge.

Role

Pure data — Model has no render() method and never mentions Camera or Renderer. Culling and submission are the caller's job: for each part, combine model.world_transform * part.transform, decide visibility against whatever Frustum the caller is culling with, and call Renderer::submit(). See submitScene() in sandbox/model_test/main.cpp for the reference loop — that function, not Model or Camera, is what ties "a group of models" to "a camera" for one frame. No node hierarchy or scene graph beyond the flat part list — see loadGltf for how a glTF node tree collapses into it. Each part can independently be a StandardMesh or an InstancedMesh — see Material Mesh.

Depends on / depended on by

Depends on graphics::primitives::scene::Mesh (the concept, StandardMesh, InstancedMesh) and Material only — no Renderer, no Camera. Built by scene::loadGltf, which returns a std::vector<Model> directly (one per glTF scene root node that contributes a mesh); nothing owns a single Model on its behalf — the old scene::Scene wrapper that used to hold one no longer exists.

Public API

struct ModelPart {
    std::variant<graphics::primitives::scene::StandardMesh, graphics::primitives::scene::InstancedMesh> mesh;
    Eigen::Matrix4f transform;        // local to the model's own origin
    graphics::primitives::scene::Material material;
    Eigen::AlignedBox3f local_bounds; // mesh-space AABB, pre-transform; for frustum culling

    void convertToStandard();    // shares buffers, no re-upload; warns and no-ops if already that kind
    void convertToInstanced();   // lossy for the reverse direction -- see graphics::primitives::scene::Mesh
};

// Transform the 8 local corners and re-fit; loose for a rotated box but never smaller than true.
Eigen::AlignedBox3f worldBounds(const Eigen::Matrix4f& world_matrix, const Eigen::AlignedBox3f& local);

class Model {
    // Placed on top of every part's own transform by the caller. Identity by default --
    // a Model with no placement set renders exactly where its parts' transforms already put it.
    Eigen::Matrix4f world_transform = Eigen::Matrix4f::Identity();

    template <graphics::primitives::scene::Mesh T>
    void addPart(T mesh, Eigen::Matrix4f transform, graphics::primitives::scene::Material material, Eigen::AlignedBox3f local_bounds);

    u32 partCount() const;
    std::vector<ModelPart>& mutableParts();
};

Worth knowing

  • Meshes only, deliberately. An earlier version of this class also held Lights directly, which didn't make sense — a light illuminates a model, it isn't a kind of geometry. A later version wrapped Models and Lights together in a scene::Scene, which turned out to buy nothing either — every load produced exactly one Model, so the wrapper just added a layer around a list that was already the right shape. loadGltf now returns std::vector<Model> and std::vector<Light> directly.
  • No static factory — unlike Mesh/Surface, Model doesn't allocate any GPU resource itself, it just aggregates already-created meshes, so ordinary construction + addPart() is enough.
  • addPart<T>() is templated, constrained by graphics::primitives::scene::Mesh, and explicitly instantiated for StandardMesh/InstancedMesh in model.cpp — same pattern as Renderer::renderMesh<T>(). Keeps the real function body out of the header while still accepting either mesh kind at the call site; a third Mesh-satisfying type would need its own explicit instantiation line added. Its trailing local_bounds is the mesh-space AABB loadGltf computes per primitive (from the glTF POSITION accessor's declared min/max, or a vertex scan when those are absent).
  • Culling lives in the caller's loop, not on Model. worldBounds() (a free function, promoted out of a caller's private helper) transforms the eight local corners by model.world_transform * part.transform and re-fits an axis-aligned box around them — loose for a rotated box but never smaller than the true bounds, so it never culls something visible. submitScene() in sandbox/model_test/main.cpp is the reference: it only culls StandardMesh parts against Frustum::intersects(); InstancedMesh parts are always submitted, since their per-instance transforms live in the instance buffer and aren't culled yet, so one part's AABB can't stand in for the whole grid.
  • mutableParts() returns ModelPart&, not const — a caller submitting an InstancedMesh part needs mutable access so it can upload a dirty instance buffer and clear the flag (InstancedMesh::uploadIfDirty()) before drawing. StandardMesh parts pay the same non-const requirement for free even though they never actually mutate.
  • Dispatching to the right Renderer::submit<T>() instantiation happens via std::visit over ModelPart::mesh with a generic lambda in the caller's loop — the compiler picks the right template instantiation per alternative, no manual type switch needed.
  • material is always present and rides along, untouched by Model itself. addPart()'s trailing Material parameter has no default — building one needs a gpu::Device, so unlike the old std::optional<Texture> = std::nullopt shape, there's no device-free default to fall back to. scene::loadGltf is the only caller and always builds a real one via loadMaterial(), including for a primitive with no glTF material at all (defaults, both textures absent). Whatever the Material holds just gets forwarded into Renderer::renderMesh() during render() — optionality (a texture present or not, still background-loading or not) lives entirely inside Material/Texture now, one level down from Model.
  • No CPU-side vertex/index retention. convertToStandard()/ convertToInstanced() reuse the existing GPU buffers rather than rebuilding from original geometry (which ModelPart doesn't keep a copy of) — see StandardMesh::fromInstanced()/InstancedMesh::fromStandard(). Converting instanced → standard therefore drops the per-instance transform list; there's no way to recover it afterward.
