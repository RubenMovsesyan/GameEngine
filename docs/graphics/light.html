graphics::Light

Plain data mirroring glTF's KHR_lights_punctual fields, plus the owning node's resolved world position/direction.

Role

A punctual light: directional, point, or spot. No GPU resource, no behavior beyond display() — graphics::LightManager is what turns a set of these into something the GPU can read.

Depends on / depended on by

Depends only on Eigen + utils::Display. Populated by scene::loadGltf (the only place that knows about cgltf_light); read by LightManager (packs into a GPU buffer) and scene::Scene (owns a std::vector<Light>).

Public API

enum class LightType { Directional, Point, Spot };

class Light {
    LightType type;
    Eigen::Vector3f color;      // linear RGB
    f32 intensity;              // raw glTF units: lux (Directional) or candela (Point/Spot)
    Eigen::Vector3f position;   // world space; meaningful for Point/Spot
    Eigen::Vector3f direction;  // world space, normalized; meaningful for Directional/Spot
    f32 range;                 // meters; 0 means infinite range per glTF spec
    f32 spot_inner_cone_angle; // radians; Spot only
    f32 spot_outer_cone_angle; // radians; Spot only

    std::string display() const;
};

Worth knowing

  • Intensity is unconverted. glTF's units are physically real — directional is lux, point/spot is candela — and real Blender-exported scenes produce values in the tens or hundreds of thousands (a 1000W Blender point light exports as roughly 1000 / (4π) × 683 ≈ 54,300 candela; a 1000 W/m² sun exports as 683,000 lux — Blender's exporter multiplies by 683 lm/W, the standard photometric luminous-efficacy constant, then divides by 4π steradians for point lights since they radiate over the full sphere). Nothing here rescales that. See Renderer for where exposure/tonemapping deals with it.
  • direction is the direction the light travels (glTF's local -Z rotated into world space), not the direction toward the light — shading code needs -direction for a standard N·L term.
  • range == 0 means "infinite range" per the glTF spec's own convention for an unset field, not "zero-range light."
