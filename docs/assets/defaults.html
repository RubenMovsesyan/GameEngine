assets::loaders::registerDefaultLoaders

Registers every built-in loader on an AssetLibrary in one call.

Role

The single place that maps asset types to the engine's built-in loaders. A sandbox calls it once after creating its library, then overrides individual types with setLoader if it needs to.

Registered

TypeFromLoader
assets::loaders::GltfAsset.glb / .gltfloadGltf
scene::Modelsplit from GltfAssetall root models merged by mergeModels
std::vector<Light>split from GltfAssetthe file's lights
graphics::primitives::scene::Textureimage file (stb_image formats)loadTexture, sRGB

Public API

void registerDefaultLoaders(AssetLibrary& library);

Worth knowing

  • No Material loader: materials have no file format of their own yet; they arrive inside a glTF.
  • The Texture loader assumes color data (sRGB). For linear data (roughness maps, normal maps) register an override, or add a separate wrapper type, since the key is by type.
