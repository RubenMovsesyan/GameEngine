app::Window

Strictly the window: GLFW, the surface, input polling. Nothing else in the engine touches GLFW directly.

Role

Wraps a GLFWwindow*, creates the VkSurfaceKHR from it, and registers GLFW's key/mouse-button/cursor-pos/scroll callbacks — the only place any of that GLFW machinery is touched. Each callback is a free-function trampoline that recovers the Window* via glfwGetWindowUserPointer and forwards straight into InputState. Also owns cursor capture (hide + lock for mouse-look).

Depends on / depended on by

Depends on gpu::Instance (to create a surface against), InputState (forwards GLFW events into it), and GLFW. Owned by app::Application, constructed first in its initializer list — takes Application's InputState by reference directly rather than reaching for it through Application, since Application's own header includes Window's, and routing the other way round would be a circular include.

Public API

std::span<const char* const> requiredInstanceExtensions();  // free function, calls glfwInit()

class Window {
    Window(Application& app, InputState& input, int width, int height, const char* title);

    Application& application() const;
    InputState& input() const;
    VkSurfaceKHR createSurface(const gpu::Instance&) const;

    bool shouldClose() const;
    VkExtent2D framebufferExtent() const;
    static void poll();

    void setCursorCaptured(bool captured);   // GLFW_CURSOR_DISABLED (hidden, locked, relative motion) or NORMAL
    void toggleCursorCapture();
    bool isCursorCaptured() const;
};

Worth knowing

  • requiredInstanceExtensions() is what feeds gpu::InstanceConfig::required_extensions — the one place GLFW's needs cross into gpu/, and it crosses as a plain std::span, not a GLFW type.
  • Move/copy deleted, same as every other owning-a-native-handle class in this engine.
  • setCursorCaptured(true) is what makes mouse-look usable — GLFW's DISABLED cursor mode hides the cursor and reports unbounded relative motion instead of clamping at the window edge. main.cpp's renderLoop toggles it on Escape via app::Application::toggleCursorCapture(); see Application.
