app::Window

Strictly the window: GLFW, the surface, input polling. Nothing else in the engine touches GLFW directly.

Role

Wraps a GLFWwindow* and creates the VkSurfaceKHR from it. Holds a reference back to its owning Application so future callbacks (resize, input) can reach into the application directly rather than routing through free functions.

Depends on / depended on by

Depends on gpu::Instance (to create a surface against) and GLFW. Owned by app::Application, constructed first in its initializer list.

Public API

std::span<const char* const> requiredInstanceExtensions();  // free function, calls glfwInit()

class Window {
    Window(Application& app, int width, int height, const char* title);

    Application& application() const;
    VkSurfaceKHR createSurface(const gpu::Instance&) const;

    bool shouldClose() const;
    VkExtent2D framebufferExtent() const;
    static void poll();
};

Worth knowing

  • requiredInstanceExtensions() is what feeds gpu::InstanceConfig::required_extensions — the one place GLFW's needs cross into gpu/, and it crosses as a plain std::span, not a GLFW type.
  • Move/copy deleted, same as every other owning-a-native-handle class in this engine.
