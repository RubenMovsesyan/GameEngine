assets::loaders::loadTexture / decodeImage

Image file to Texture, plus the shared stb_image decode step the glTF loader also uses.

Role

loadTexture(path) reads the file's bytes now, then hands decoding to Texture::loadAsyncThread: it returns a placeholder immediately and the real image is swapped in by Texture::drainUploads() (called by Presenter each frame). decodeImage is the stb_image step, shared with loadGltf's embedded textures. This translation unit owns STB_IMAGE_IMPLEMENTATION.

Public API

// stb_image decode to tightly packed RGBA8. Fatal on failure. Safe off the sokol thread.
graphics::primitives::scene::DecodedPixels decodeImage(std::vector<u8> encoded_bytes);

// Placeholder now; decoded on a background thread, swapped in by Texture::drainUploads().
graphics::primitives::scene::Texture loadTexture(const std::filesystem::path& path);

Worth knowing

  • Always decodes to tightly packed RGBA8 (STBI_rgb_alpha), whatever the source channel count.
  • decodeImage can run (and fail fatally) on the background thread; process-wide exit is fine from any thread.
