gpu::Instance

The VkInstance wrapper — the very first Vulkan object, and the root everything else (device, surface) is created from.

Role

Owns exactly one VkInstance. Enables the Khronos validation layer when available (warns and continues without it otherwise, rather than failing). Nothing else — no device selection, no surface, no window concepts reach this class.

Depends on / depended on by

Depends on nothing but the Vulkan headers. gpu::Device is constructed from one; app::Window::requiredInstanceExtensions() supplies the extension list InstanceConfig::required_extensions needs (GLFW's required surface extensions) — gpu/ itself never calls into GLFW.

Public API

struct InstanceConfig {
    const char* app_name = "GameEngine";
    std::span<const char* const> required_extensions{};
    bool validation = true;
};

class Instance {
    explicit Instance(const InstanceConfig& cfg = {});
    VkInstance handle() const;
};

Worth knowing

  • Move/copy are deleted — an Instance is never relocated, only referenced.
  • Validation layer absence is a warning (RLOG(LL_WARN, ...)), not fatal — the engine still runs, just without the extra diagnostics.
  • Uses Vulkan 1.3 (VK_API_VERSION_1_3) unconditionally; NVRHI's requirements (dynamic rendering, synchronization2, timeline semaphores — see Device) assume that floor.
