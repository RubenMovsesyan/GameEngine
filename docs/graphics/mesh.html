graphics::Mesh

A GPU-resident vertex buffer + index buffer. The smallest drawable unit in the engine.

Role

Everything drawable is a Mesh — one vertex buffer, one index buffer, both allocated and uploaded via gpu::Device::createBuffer. No material, no transform of its own (that's scene::ModelPart's job).

Depends on / depended on by

Depends on gpu::Device. Built by scene::loadGltf (one per glTF primitive) and drawn by graphics::Renderer::renderMesh().

Public API

struct Vertex {
    Eigen::Vector3f position;
    Eigen::Vector3f normal;
    Eigen::Vector2f uv;
};

class Mesh {
    static Mesh create(const gpu::Device&, std::span<const Vertex> vertices, std::span<const u32> indices);

    nvrhi::IBuffer* vertexBuffer() const;
    nvrhi::IBuffer* indexBuffer() const;
    u32 indexCount() const;
};

Worth knowing

  • Private constructor + static factory — matches every GPU-resource class in this engine (Surface does the same); protects the invariant that a Mesh always has real, uploaded buffers.
  • Vertex matches glTF's POSITION/NORMAL/TEXCOORD_0 attribute set directly — no per-vertex color, since albedo comes from textures in this pipeline's model (once a material system exists), not vertex color.
  • Indices are always u32 — scene::loadGltf widens whatever width the source glTF accessor uses (u8/u16/u32) on load, so Mesh/Renderer never need to handle a variable index format.
