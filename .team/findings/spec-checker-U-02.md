## Issues
1. AC-5's `grep ... "returns nothing"` sub-clause is unsatisfiable by a correct implementation — severity: medium
   The current AC-5 says: `grep -n 'struct RenderTarget\|makeColorTarget\|makeDepthTarget' src/graphics/deferred_renderer.*` "returns nothing". Reproduce: run that grep from the repo root at `ffbd8b4` -> 7 matches at `src/graphics/deferred_renderer.cpp:233-239`, all of them `m_x = makeColorTarget(...)` / `makeDepthTarget(...)` *call sites* inside `rebuildTargets()`. The renderer is supposed to compose the primitive, which means it must call `makeColorTarget`/`makeDepthTarget`, so the grep can never be empty for a working renderer. The pre-rewrite wording of this AC (see `git log -p -S'returns nothing' -- .team/spec.md`) read "No `RenderTarget` struct or `makeColorTarget`/`makeDepthTarget` *definition* remains in `deferred_renderer.{hpp,cpp}`" — the rewrite dropped "definition". Recommended fix is to the spec, not the code: restore the "no *definition*" phrasing, or change the check to `grep -n 'struct RenderTarget {\|RenderTarget makeColorTarget(\|RenderTarget makeDepthTarget(' src/graphics/deferred_renderer.*` returns nothing (which currently passes, rc 1). The implementation already keeps all three definitions solely in `render_target.{hpp,cpp}` and only calls them from the renderer, so the design intent of AC-5 is satisfied.
