graphics::primitives::pass::FullscreenPass

The pipeline for one fullscreen-triangle fragment shader, plus a one-line draw().

Role

Screen-space passes — deferred lighting, the sky, tonemap, FXAA, the shadow-map debug blit, the Presenter's swapchain blit — all have the same pipeline shape: no vertex buffer, no depth, one colour attachment, and a three-vertex draw of the shared fullscreen_vs triangle. FullscreenPass is that shape. create() makes the pipeline from a generated shader desc; draw() binds it, applies your bindings, runs an optional uniform callback, and issues sg_draw(0, 3, 1).

It deliberately does not own the sg pass. A pass often holds more than one draw — the deferred renderer's final pass runs FXAA, then the shadow-map debug blit, then the debug-line overlay, in one pass — so the caller opens and closes the pass and calls draw() as many times as it needs.

Depends on / depended on by

Depends on nothing but <sokol_gfx.h>. Used by DeferredRenderer (its five screen-space passes), by TonemapPass / FxaaPass (each wraps one), and by Presenter (the blit).

Public API

// output_format left kSwapchainColorFormat (== 0) is resolved against the swapchain
// at pipeline creation; pass an explicit format for an offscreen attachment.
inline constexpr sg_pixel_format kSwapchainColorFormat = static_cast<sg_pixel_format>(0);

class FullscreenPass {
    static FullscreenPass create(const sg_shader_desc* shader_desc,
                                 sg_pixel_format output_format, const char* label);

    // An sg pass must already be open.
    void draw(const sg_bindings&, const std::function<void()>& apply_uniforms = {}) const;
};

Worth knowing

  • Two formats, not one. create() sets colors[0].pixel_format = output_format, and it sets depth.pixel_format = SG_PIXELFORMAT_NONE only when output_format != kSwapchainColorFormat. An offscreen target has no depth attachment, so its pipeline must declare depth NONE; a swapchain-resolved pipeline must leave depth unset so sokol fills in the swapchain's real depth format. Getting this wrong trips VALIDATE_APIP_SWAPCHAIN_DEPTH_FORMAT.
  • kSwapchainColorFormat is (sg_pixel_format)0 — sokol's "resolve me" sentinel — which is a different value from SG_PIXELFORMAT_NONE (that means "no attachment at all").
  • draw() takes the uniform-packing as a std::function callback. That is one indirect call (and possibly one small heap allocation) per invocation, on the render path — acceptable at the ≤6 fullscreen draws a frame has, but not a pattern to copy into a hot inner loop.
