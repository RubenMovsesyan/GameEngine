graphics::Surface

Either a swapchain image or an offscreen render target — same object either way, since both are "something to render into, or sample as a texture."

Role

Bundles a texture with a matching one-color-attachment framebuffer. Two factories cover the two cases this engine needs: wrapping an existing swapchain image, or allocating a fresh offscreen texture (used for every intermediate render target — the HDR lighting output, PostProcessChain's ping-pong scratch buffers).

Depends on / depended on by

Depends on gpu::Device. Used by Renderer (swapchain surfaces, HDR color target) and PostProcessChain (ping-pong targets).

Public API

class Surface {
    static Surface fromSwapchainImage(const gpu::Device&, nvrhi::TextureHandle, VkExtent2D);
    static Surface createOffscreen(const gpu::Device&, VkExtent2D, nvrhi::Format format = nvrhi::Format::BGRA8_UNORM);

    nvrhi::ITexture* texture() const;
    nvrhi::IFramebuffer* framebuffer() const;
    VkExtent2D extent() const;
};

Worth knowing

  • Private constructor + static factories, same pattern as Mesh — an invariant (texture and framebuffer always match) worth protecting.
  • createOffscreen's default format is BGRA8_UNORM (matches the swapchain), but every current caller that needs HDR passes RGBA16_FLOAT explicitly.
