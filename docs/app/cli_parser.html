app::CliParser

Minimal typed --flag value parser. Mirrors buildcpp's own defineArg/parseArgs/arg pattern.

Role

Define expected flags with their type up front, parse argv once, read values back typed. A type-erased-by-std::variant dispatch, plus bool as a presence-only "nothing" category (e.g. --verbose with no value) that buildcpp's own version doesn't have.

Depends on / depended on by

Depends only on the standard library. Used directly in main() (sandbox/model_test/main.cpp) to parse --model <path>.glb.

Public API

template <typename T>
concept CliArgValue = /* string, bool, or any integer/float type */;

class CliParser {
    CliParser(int argc, char** argv);

    template <CliArgValue T> void defineArg(const std::string& name);
    void parse();
    template <CliArgValue T> std::optional<T> arg(const std::string& name) const;
};

Worth knowing

  • defineArg<bool> means "presence-only flag" — parse() sets it true just from seeing --name, no following value consumed.
  • Unknown flags and unparseable values are fatal (RLOG(LL_FATAL, ...)) — a bad CLI argument isn't silently ignored.
  • arg<T>() returns std::nullopt both when the flag was never seen and when the wrong type is requested for a flag that was defined differently — same "absent" signal either way.
