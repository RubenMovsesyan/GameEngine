scene::Model

A flat collection of meshes, each with its own local transform. Geometry only — no lights, no materials.

Role

Rendering a model means rendering each part individually: render() loops its parts and calls Renderer::renderMesh() once per part, combining the caller-supplied world transform with each part's local transform. No node hierarchy or scene graph — a flat list is all that's needed for what's actually loaded today.

Depends on / depended on by

Depends on graphics::Mesh/Renderer/Camera. Built by scene::loadGltf (one Model per glTF file, gathering every mesh primitive in the node tree); owned by scene::Scene.

Public API

struct ModelPart {
    graphics::Mesh mesh;
    Eigen::Matrix4f transform; // local to the model's own origin
};

class Model {
    void addPart(graphics::Mesh mesh, Eigen::Matrix4f transform = Eigen::Matrix4f::Identity());
    void render(graphics::Renderer&, const Eigen::Matrix4f& world_transform, const graphics::Camera&) const;
    u32 partCount() const;
};

Worth knowing

  • Meshes only, deliberately. An earlier version of this class also held Lights directly, which didn't make sense — a light illuminates a model, it isn't a kind of geometry. scene::Scene exists specifically to hold both Models and Lights together; Model went back to exactly this shape.
  • No static factory — unlike Mesh/Surface, Model doesn't allocate any GPU resource itself, it just aggregates already-created Meshes, so ordinary construction + addPart() is enough.
